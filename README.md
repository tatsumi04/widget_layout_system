# Widget Layout System

ウィジェットのレイアウトを、ユーザーが自由に作成・調整できる iOS アプリです。

対応OSは iOS 17 以降です。

設計書は [docs/design.md](docs/design.md) を参照してください。

## 操作方法

### ウィジェットを追加する

画面下部の色付きの円をキャンバスへドラッグして離します。ドロップ位置に応じて、既存のレイアウトが分割され、新しいウィジェットが追加されます。

### ウィジェットを移動する

キャンバス上のウィジェットをドラッグします。キャンバス内で離すと、その位置に応じてレイアウトが組み直されます。

### ウィジェットを削除する

キャンバス上のウィジェットをキャンバス外へドラッグして離します。

### 複数選択・色変更・削除

ウィジェットを長押しすると選択モードに入ります。選択モードでは、ウィジェットをタップして選択・選択解除できます。

- 色変更: 選択したウィジェットに色を適用します。
- 削除: 選択したウィジェットをまとめて削除します。
- 入れ替え: ウィジェット２つ選択して、場所を入れ替えます。
- キャンセル: 選択モード開始時の状態へ戻します。
- 完了: 現在の変更を確定して選択モードを終了します。

### シャッフル

ウィジェットまたは追加用の色をドラッグ中に、キャンバス中心の周りを2周なぞるとシャッフルが実行されます。

シャッフルでは、既存ウィジェットを維持したまま、位置・大きさ・形状をランダムなレイアウトへ組み替えます。実行後に表示される「元に戻す」で直前の配置へ戻せます。

## コード構成

- `layout_app/ContentView/`: `ContentView` の画面状態と、選択・シャッフル・ドラッグ操作ごとの実装
- `layout_app/Views/`: キャンバス、ウィジェット、追加用ドックなどの画面部品
- `layout_app/Layout/`: レイアウトツリーの計算、追加・移動・削除・シャッフルの規則
- `layout_app/Models/`: ウィジェットとレイアウトツリーのデータモデル
- `layout_app/Support/`: 色変換や座標取得などの補助機能

## コーディング方針

- UIは SwiftUI で実装します。
- レイアウトの計算は `LayoutEngine` に集約し、ビューは計算結果を描画します。
- レイアウト変更時は最小タイルサイズを守ります。
- 操作に伴う一時的な状態は `ContentView` と `CanvasView` が保持し、永続的な配置は `LayoutNode` で表現します。
