# 設計書

## 目的

Widget Layout System は、ユーザーが複数のウィジェットをキャンバス上へ配置し、自分に合うレイアウトを作れるようにするアプリです。

ドラッグ操作による直接的な配置変更に加えて、シャッフルによるレイアウト提案を提供します。配置に迷ったときに、ランダムな形状や位置から新しい候補を見つけられることを目指します。

## 設計思想

- 操作対象をキャンバス上で直接動かせること
- 操作の追加や変更をしやすくすること
- 小さすぎて扱いにくいウィジェットを作らないこと
- シャッフルなどの自動操作は、元に戻せること
- 見た目の変化をアニメーションで伝え、操作結果を理解しやすくすること

## 主要機能

- 色付きウィジェットの追加
- ドラッグによる移動とキャンバス外へのドラッグによる削除
- 長押しで開始する複数選択、色変更、削除
- ドラッグ中に行う渦巻きジェスチャーによるシャッフル
- シャッフル直後のUndo

## レイアウトモデル

配置は `LayoutNode` のツリーで表します。

- `leaf`: 1つのウィジェットIDを表す葉
- `split`: 領域を横方向または縦方向に分割するノード

`LayoutEngine` はこのツリーから各ウィジェットの矩形を計算します。追加・移動・削除・シャッフルのすべてで、最小タイルサイズを満たすか確認してからレイアウトを採用します。

## シャッフルの流れ

1. 渦巻きジェスチャーを検出する
2. シャッフル前の `LayoutNode` をUndo用に保存する
3. 現在のウィジェットIDを使い、新しい分割ツリーをランダムに生成する
4. 最小タイルサイズを満たし、現在と異なる候補を採用する
5. キャンバスの回転とタイルの変形をアニメーションで表示する
6. ユーザーはトーストの「元に戻す」で直前の配置へ戻せる

候補を作れない場合は、既存ツリーの形状を維持したままウィジェットの位置だけを入れ替えます。

## 主な役割

| 要素 | 役割 |
| --- | --- |
| `ContentView` | 画面全体の状態管理、操作結果の確定、選択モードとシャッフルの制御 |
| `CanvasView` | レイアウトの描画、タイルへのジェスチャー設定、渦巻きの検出 |
| `LayoutEngine` | ツリーからの矩形計算、レイアウトの追加・移動・削除・シャッフル |
| `WidgetTile` | 個々のウィジェットの見た目と選択状態の描画 |
| `LayoutNode` | ウィジェット配置を表すツリー構造 |
